# Проект 

**HHSql** - проект, с помощью которого можно получить данные о компаниях и вакансиях с сайта hh.ru, 
спроектировать таблицы в базе данных PostgreSQL и загрузить полученные данные в созданные таблицы.

# Описание проекта

Проект предусматривает реализацию следующих задач:
1. Получить данные о работодателях и их вакансиях с сайта hh.ru. 
Для этого используется публичный API hh.ru и библиотека requests.
2. Спроектировать таблицы в БД PostgreSQL для хранения полученных данных о работодателях и их вакансиях. 
Для работы с БД используется библиотека psycopg2.
3. Реализовать код, который заполняет созданные в БД PostgreSQL таблицы данными о работодателях и их вакансиях.
4. Создать класс DBManager для работы с данными в БД.

## Использование

В модуле **"hh_api"** создается класс **"HeadHunter"** с методами, которые реализуют 
проверку подключения к API сайта "hh.ru", а также получения сведений о работодателях и вакансиях.

```
# Пример использования
hh_obj = HeadHunter()
found_employers = hh_obj.get_employers(9694561, 5331842)
found_vacancies = hh_obj.get_vacancies(found_employers)
```

В модуле **"dbmanager.py"** реализованы методы для работы с отобранными данными
по работодателям и вакансиям.

```
# Пример использования 
hh_obj.get_companies_and_vacancies_count("mydatabase", params)
```

В проекте в модуле **utils.py** реализованы вспомогательные функции, которые аккумулируют данные для основной функции.
В частности, реализована функция взаимодействия с пользователем, через которое мы узнаем от него, 
какие сведения он хочет получить.


В модуле **main.py** реализована основная функция проекта, которая получает данные для заполнения таблиц,
создает базу данных, таблицы, и через взаимодействие с пользователем предоставляет интересующие его сведения.
